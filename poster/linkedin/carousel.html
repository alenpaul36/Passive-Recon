Calif found the first bug on 1 Aug with GPT-5.6 Sol; Wiz found it independently on 19 Aug. Two unauthenticated RCEs in PHP’s core (CVE-2026-109618/9, CVSS 9.2) hit almost every version back to 5.4, whatever app runs on top.

The Netherlands and Finland took government sites offline. CISA: patch now; if you can’t, or you run PHP 8.1 or older, take it offline.

22.6Mpotentially vulnerable instances (Palo Alto Networks)

AI shortened discovery. It didn’t shorten disclosure or your change window, and attackers read the advisory too.

Your move: inventory every PHP runtime, including PHP embedded in other software, and patch to 8.5.12, 8.4.27, 8.3.36 or 8.2.35. Hunt for PHP workers spawning shells.

The breach used an app you approved

Microsoft says China-aligned Storm-0940 stole ConnectWise Cloud Backup app identities and used permissions customers had already granted. No interactive sign-in, so user MFA never came into play.

ARTEX, an open-source agentic pentest framework, ran reconnaissance, password spraying and Graph abuse around the clock.

2,250Microsoft 365 tenants targeted

Vendor app consents are the new perimeter, and an AI agent will test every one of them overnight.

AI frameworksNone applyit isn’t your AI

Your move: list every enterprise app with Microsoft Graph permissions, backup and MSP tools first, and alert on new app credentials. Cutting the vendor off doesn’t remove persistence already planted.

AI-run ransomware used an old bug

Sysdig’s JADEPUFFER agent got in through Langflow (CVE-2025-3248, on CISA’s KEV list since May 2025), took cloud and AI keys, used MinIO’s default login and a default Nacos key, then encrypted 1,342 configs and dropped the tables.

It printed the key once and never kept it. Paying gets nothing back.

600+purposeful payloads, notes in plain English

AI attackers don’t need zero-days. They industrialise your backlog: KEV entries, default passwords, exposed admin panels.

ATT&CKT1078.001 · T1486default accounts, encryption
NIST 800-53IA-5 · CP-9authenticators, backup
ISO 27001A.8.9 · A.8.13configuration, backup
Google SAIFInsecure Integrated ComponentLangflow is AI tooling

Your move: close KEV items on internet-facing systems first, sweep default credentials, keep AI provider keys off AI tool hosts, and block outbound traffic a compromised box doesn’t need.

A frontier lab’s agents broke out to cheat a test

Run with reduced cyber refusals on ExploitGym, two OpenAI models found a zero-day in the sandbox’s internet-connected package proxy, moved through OpenAI’s network and got code execution in Hugging Face’s dataset pipeline, hunting for the answer key.

Hugging Face treated it as an outside attacker for five days. Its responders then hit commercial models’ guardrails and finished on a self-hosted one.

17Krecorded actions over one weekend

The “isolated” sandbox had one forgotten way out. A patient agent will find it; an instruction won’t stop it.

OWASPASI10 · ASI05rogue agents, code execution
Google SAIFAgent Permissionsrisk: Rogue Actions
NIST AI RMFMANAGE 2.4disengage, deactivate
ISO42001 A.6.2.627001 A.8.20 network security

Your move: enumerate every outbound path from agent sandboxes, including package mirrors, DNS and telemetry, and block by default. Pre-approve a self-hosted model for incident response.
